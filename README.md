# Petanque-amateur
Gestionnaire de tournois de pétanque sous Windows avec interface graphique

Ce logiciel permet de gérer sur PC des tournois de pétanque en doublettes ou triplettes
sous forme éliminatoire ou en plusieurs tours, en équipes formées ou mêlées...
Depuis la saisie des équipes jusqu'au classement du tournoi, en passant par les tirages aléatoires...
L'interface est graphique.
Les données sont enregistrées dans des fichiers csv compatibles avec les tableurs usuels.

Voir documentation jointe au format rtf pour en savoir plus !
